CMS Data Analysis (Medicare/Medicaid)
Python solution for the Health Partners data engineering assessment, plus the bonus food truck ERD.
Contents
File	Description
`cms_analysis.ipynb`	Required exercise: Python analysis of CMS Medicare/Medicaid data
`food_truck_erd.md`	Bonus: relational ERD for a food truck company (added if completed)
Approach
Load the CMS dataset
Inspect and clean the data (types, nulls, duplicates)
Answer the exercise questions with pandas
Summarize findings and assumptions
Assumptions and design decisions are documented in markdown cells inside the notebook.
How to run
```bash
pip install pandas jupyter
jupyter notebook cms_analysis.ipynb
```
Notes
Python 3.x, pandas
Any data files used are referenced in the notebook; large source files are not committed.
